VirusTotal integration

Optional. Your key is used only when you manually request a VirusTotal lookup. Local PrivacyLens checks work without it.

Unchecked: the key stays in browser-session memory until restart or extension reload/disable/update. Checked: only the key is stored locally in this browser profile, without sync. PrivacyLens does not encrypt it as a secret vault; someone with access to the profile may recover it.

Reading configuration…

The saved key is never shown here. Saving does not test it or send a request. Forget removes the extension's copies; it does not revoke the key at VirusTotal.

Before using VirusTotal

Confirmed hostname lookups leave your browser. VirusTotal says queried indicators may be scanned and included in its shared dataset. Do not check confidential or personal hostnames.

The public API is for permitted personal/academic, non-commercial use, with 4 requests per minute and 500 per day. PrivacyLens spaces requests and respects quota errors. Account restrictions and other clients still apply.
