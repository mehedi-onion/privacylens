# PrivacyLens artwork

`logo.png` is the supplied `eddedd55-39e5-4da7-b96d-77f9b93a4987.png`, copied without changes. The horizontal wordmark is used in the popup, extension pages and README. A light backing keeps its dark lettering readable in dark mode.

`icon-source.png` is an icon-only variant of the eye/lens mark, made with the built-in image tool. The prompt requested: “Remove all lettering. Keep only the eye/camera-lens mark on the left, centered on a square genuinely transparent canvas. Preserve its recognizable eye silhouette and aperture/lens structure, teal/green palette and dark pupil. Simplify tiny details so the mark reads at 16 and 32 pixels. No extra symbols, shadow or background.”

`icons/icon-{16,32,48,128}.png` are deterministic Lanczos resizes of that square source, with transparency preserved. The wordmark is never squeezed into a toolbar icon.
